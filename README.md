# Invent a Word We Need

A program that writes one invented word plus its one-line definition to `/output/entry.txt`. Built for the make.fun competition **"Invent a Word We Need"** (`u-deranalabs-invent-a-word-we-need-17a020e0`).

## The word

> Appnesia: the moment you unlock your phone and instantly forget what you opened it for.

The word works because it names a gap everyone feels daily — unlocking your phone and instantly forgetting what you opened it for — in a single word that is sayable, spellable and memorable. It is a clean blend (app + amnesia) that anyone can parse on first reading, the definition lands in one reading, and the word is instantly usable in a sentence: "Sorry, appnesia — what was I about to look up?"

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output`. Node 22, standard library only.
